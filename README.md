# Elora Events

Official repository for **Elora Events** — a premier full-service event planning, decoration, and catering company based in Kempton Park, Johannesburg.

---

## 📂 Repository Structure

- **[`elora-events/`](elora-events/)**: The complete responsive marketing website (HTML5, modern CSS3, vanilla JavaScript).
  - `index.html` — Homepage with hero banner, service highlights, reviews & stats
  - `about.html` — Company story, values & approach
  - `services.html` — Full-service breakdown (Planning, Decor & Styling, Catering)
  - `gallery.html` — Interactive photo gallery with category filters and full-screen lightbox
  - `contact.html` — Contact form, direct details, and interactive map embed
  - `css/styles.css` — Complete design tokens, responsive typography, and component styling
  - `js/main.js` — Modular vanilla JavaScript (navigation drawer, lightbox, animations, form handler)
  - `assets/images/` — Production-optimized website imagery and branding
- **`images/`**: Original high-resolution photo assets and raw brand imagery.

---

## 🚀 Quick Start

To preview the website locally:

1. Open `elora-events/index.html` directly in any web browser.
2. Or run a local development server from within `elora-events/`:
   ```bash
   cd elora-events
   # Using Python 3:
   python -m http.server 3000
   
   # Or using npx:
   npx serve .
   ```
   Then open `http://localhost:3000` in your browser.

For full technical details, styling tokens, and integration guidance, see [elora-events/README.md](elora-events/README.md).
